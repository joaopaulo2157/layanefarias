FLORAGESTOR ULTIMATE — EDIÇÃO HTML
====================================
Esta edição foi convertida para HTML + CSS + JavaScript puro.

COMO ABRIR
Abra index.html no navegador ou publique a pasta em GitHub Pages, Cloudflare Pages,
Netlify, Vercel ou qualquer hospedagem estática.

ARMAZENAMENTO
Os dados ficam no localStorage do navegador. O sistema inclui backup em JSON.

IMPORTANTE
Por ser HTML estático, esta edição NÃO possui banco de dados central, PHP, sessões de
servidor, usuários simultâneos, webhooks, API Pix/WhatsApp ou segurança de backend.
Ela é adequada para uso local, demonstração/protótipo e operação em um único navegador.

Para uso comercial multiusuário, mantenha a edição PHP/SQL ou conecte esta interface
HTML a um backend/API.
